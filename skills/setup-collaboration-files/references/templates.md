# Init Project — 文件模板

> 本文所有字数预算都是**缺省值**：仓库已有自己的预算文件或 CI 阈值时，以仓库声明为准。

## 根 `AGENTS.md`

预算 ≤1,950 词。常驻军规放最前，是 agent 每次真正会读的部分。

```markdown
# [项目名] AGENTS

## 常驻军规

- [一条可机械判定的硬规则，一行讲完]
- [非平凡改动必须留下决策笔记；代码与笔记同批提交；格式与判定见 `decision-notes` 技能]
- [项目特有的、每次开工都必须知道的一条]

## 0. 实施基线

- 环境：[自动提取或待补充]
- 语言/运行时：[自动提取或待补充]
- 主要技术栈：[自动提取或待补充]
- 配置根目录：[自动提取或待补充]
- 标准验证命令：[自动提取的显式命令，或待补充]

## 1. 作用

- 本文件是项目级硬规则，只保留长期约束实现结构的内容。
- 详细设计、字段说明、流程细节统一回到 `docs/`。

## 2. Source of Truth

- [若仓库有正式文档层级，写真实优先级清单；否则写最小真实优先级]
- `tools.md` / `memory.md` 只做协作辅助，不覆盖正式设计真值。
- `.agents/notes/` 是因果真理源：现状事实不写进笔记，笔记结论也不替代 `docs/`。

## 3. 架构与项目结构

- [真实的根目录职责、核心模块/子应用/包目录、关键分层或依赖方向、关键入口路径]
- [模块级约束就近写在该目录的 `AGENTS.md`，本节不复述]
- [确实提取不到时，本节只写一条待补充]

## 4. 协作文件与决策笔记规则

- 开始任务前，优先读取项目根 `tools.md`、`memory.md` 与 `.agents/notes/AGENTS.md`。
- 只读取当前项目根的协作文件；旧 `memory/archive/` 只按需读当月或最近一个归档，不批量加载历史。
- `tools.md` 记录稳定可复用的命令、路径、模式、坑点；写入前先读；不写单次任务日志。
- `memory.md` 是当前状态快照 + 最近活跃窗口；完整功能/修复闭环后整体覆盖更新，不做流水追加，移除失效项，目标 ≤120 行。
- 非平凡改动（行为 / 架构 / 跨文件契约 / 流程与工具链 / 测试策略 / 落盘格式）必须留下决策笔记，代码与笔记**同批提交**；判定表与四格写法见 `decision-notes` 技能。
- 笔记状态由目录位置决定：`proposed/`、`implemented/`、`rejected/`、`archived/`。严禁创建总索引文件。
- 已经发生的决定不能删：失效的旧笔记结论不改，标注被谁取代后移入 `archived/`；`archived/` 永久冻结。
- 被约束的代码入口留一行注释回指对应笔记。
- `docs/postmortem/` 是唯一允许写事故与血泪史的地方；结论要沉淀成一行回到本文件。

## 5. 验证、入口与关键路径

- [真实的标准验证命令]
- [真实的定向验证命令与关键文档入口；没有的项可省略]
- [关键入口路径、配置根目录、共享 skills 目录或关键生成目录]
- [确实提取不到时，本节只写一条待补充]

## 6. 项目特定规则

- [只写从现有规则、文档、结构提取出的长期约束]
- [优先写模块边界、依赖方向、真值源边界和必须遵守的实现约束]
- [缺少强信号时本节保持一条简洁说明]

## 7. 维护原则

- 本文件保持短、小、硬，≤1,950 词；超限先下沉到 `docs/` 再精简，不删约束凑数。
- 近期状态放 `memory.md`，稳定协作知识放 `tools.md`，现状事实放 `docs/`，因果取舍放 `.agents/notes/`。
- 模块级规则就近放子目录 `AGENTS.md`，不往根上堆。
- 解释性长文回到 `docs/`。
```

## 子目录 `AGENTS.md`

预算 ≤750 词。有强信号才生成，只写该作用域内的规则。

```markdown
# [目录名] 规则

- [本目录职责边界；什么属于这里，什么不属于]
- [本目录特有的实现约束、类型约定、目录禁忌]
- [跨边界调用方向：谁能调谁，禁止反向依赖]
- [本目录的验证方式，或指向根 `AGENTS.md` 的标准命令]
```

## `docs/AGENTS.md`

预算 ≤1,320 词。四条去废话守则必须齐全。

```markdown
# docs 文档标准

## 结构分层

- `architecture.md`：骨干预览，只做总导航，不写具体类型细节。
- `subsystems/`：子系统规范，承载真实类型声明与契约。
- `cookbook/`：操作实操，每步带编号和精确验证命令。
- `postmortem/`：事故复盘，真实踩雷记录、时间线、止血措施。

一事一归宿：上层只放单行链接，细节永远下沉到专属目录。

## 去废话守则

1. 只记当下事实，严禁「以前 / 现在 / 不再 / 改名为」这类变迁叙述。历史属于 git 和 `.agents/notes/`。
2. 严禁人肉手抄生成物：能由源码或 AST 推导的 API 列表、配置清单必须由代码生成，文档只负责圈定插槽。
3. 文档里的代码块必须能真实编译或运行通过。
4. 字数上限与超限处置：**下沉迁移 → 精简浓缩 → 申请提额**，按此顺序，不允许先删约束。

## 字数预算

- `architecture.md` ≤2,400 词
- 本文件 ≤1,320 词
- [仓库已有预算文件时，在这里指向它，不复制其数值口径]
```

## `docs/architecture.md` 最小骨架

只在需要新建时使用；已有文件只补缺失小节。

```markdown
# [项目名] 架构

## 全景

[按层展开模块骨架、边界与扩展点，只做总导航，不写具体类型细节]

## 子系统索引

- [子系统名] -> `subsystems/[文件名].md`

## 关键数据流

[主链路的走向；细节留给 subsystems]

## 扩展点

[新增功能应当挂在哪里；不在这里展开实现步骤]
```

## `.agents/notes/AGENTS.md`

**只写仓库不变量，不写写作方法**。四格模板、非平凡判定表、取代流程属于 `decision-notes` 技能。

```markdown
# .agents/notes 规则

本目录记录代码装不下的「为什么」：当初为什么这么定、否定过哪些方案、代价是什么。
现状事实属于 `docs/`，事故记录属于 `docs/postmortem/`，本目录只管因果取舍。

## 不变量

- 状态由目录位置决定：`proposed/` 待评审、`implemented/` 已落地、`rejected/` 已否决、`archived/` 被取代。
- 文件名：`YYYY-MM-DD-<kebab-slug>.md`，日期取决定作出或落地的日期。
- 严禁创建 `INDEX.md`、`README.md` 或任何"每篇笔记都要改一行"的总索引。
- `implemented/` 随代码更新；它只写已经发生的事实，禁止 `## Proposal` / `## 计划` / `## TODO` 类标题。
- `archived/` 永久冻结：封起来不许改。
- 已经发生的决定不能删：被取代时旧篇结论不改，标注被谁取代后移入 `archived/`；新篇引用旧篇并写清代价。
- 代码与笔记同批提交；被约束的代码入口留一行注释回指本篇。

## 写作方法

格式、非平凡判定表、四格写法与验收清单见 `decision-notes` 技能；本目录不复制它们，避免两处漂移。
```

## `CLAUDE.md` 兼容入口

```markdown
# [项目名] - 项目指令

@AGENTS.md
```

## `tools.md`

```markdown
# [项目名] Tools

## Concepts

- 本文件记录项目协作知识，不替代正式设计文档、`docs/` 或当前代码。
- [自动提取的真实真值优先级；没有正式 docs 体系时写最小真实优先级]
- [自动提取的主链路或核心边界；没有则可省略]

## Read First

- [真实存在的关键文档入口]

## Tools

- [自动提取的标准验证命令]
- [自动提取的定向验证命令；没有则可省略]
- [关键入口路径：app/router/server/main/service/cli]
- [配置根目录、共享 skills 目录或关键生成目录]
- [已安装的项目共享 skills；存在则写]

## Patterns

- [仍有效、会重复出现的稳定实现模式或协作规律]

## Pitfalls

- [可复用的坑点：环境差异、测试陷阱、路径/事务/沙箱问题]
- [血泪史本身写明指向 `docs/postmortem/` 的条目，这里只留结论]
```

生成原则：

- 只记录长期可复用的协作知识，不写当前单次任务日志。
- `Tools` 优先写精确命令、具体路径、明确入口，不写空泛口号。
- `Patterns` 只收明确仍有效、会重复出现的稳定做法。
- `Pitfalls` 只收可复用坑点，当天流水账不放。
- 单个 section 没有足够信号时保留一条 `[待补充：当前仓库暂无足够稳定信号]`，不要堆占位符。

## `memory.md`

结构固定为五节，**不含"关键决策"节**——决策的唯一家在 `.agents/notes/`。

```markdown
# [项目名] 项目状态

> 本文件是当前状态快照 + 最近活跃窗口，允许覆盖更新。
> 决策与取舍见 `.agents/notes/`，稳定规律见 `tools.md`，现状事实见 `docs/`。

## 当前基线

- [自动提取的验证基线；没有则待补充]
- 最后更新：[今天日期]

## 已完成能力

- [当前仓库仍成立的闭环能力；优先来自现有规则/文档/当前代码，不足时再参考近期提交]

## 进行中 / 未完成

- [根据当前规则、文档和近期提交提炼；没有就待补充]

## 仍需注意的坑点

- [可复用坑点；没有则待补充]

## 最近活跃窗口

- [最近 2~3 天的 3~8 条一句话摘要]
```

初始化约束：目标 ≤120 行；"已完成能力"不搬运 commit 标题；"进行中"只写能明确证明的方向；"最近活跃窗口"只覆盖最近 2~3 天。
